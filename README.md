## 一、启动流程说明

### 1. 引导加载器阶段 (Bootloader)
- **bootasm.S**: BIOS加载引导扇区到0x7C00，初始化16位实模式，启用A20地址线，切换到32位保护模式
- **bootmain.c**: 从磁盘读取ELF格式的内核镜像，验证ELF头部，加载内核程序段到内存
- **引导扇区限制**: 必须 ≤ 510字节，最后2字节为魔数0x55AA

### 2. 内核入口阶段
- **entry.S**: 内核入口点，初始化页表，启用分页机制，设置栈指针，跳转到main函数
- **页表初始化**: 使用entrypgdir建立初始页表映射

### 3. 内核初始化阶段
- **main.c**: 内核主函数，初始化控制台、内存管理、进程管理等子系统
- **启动流程**: bootblock → bootasm.S → bootmain.c → entry.S → main()

## 三、个人总结

### 遇到的问题及解决方案
1. **make命令未找到**：安装WSL和build-essential工具链
2. **GCC版本兼容问题**：修改Makefile去掉-Werror或降低GCC版本
3. **boot sector大小限制**：引导扇区代码必须精简，不能添加过多打印函数
4. **boot阶段cprintf不可用**：引导阶段控制台未初始化，需使用BIOS中断或直接写屏
5. **Git认证失败**：使用SSH密钥或Personal Access Token替代密码

### 实践收获
1. **深入理解操作系统启动流程**：从BIOS加载到内核初始化的完整过程
2. **掌握实模式到保护模式切换**：A20地址线、GDT、段寄存器设置
3. **理解ELF文件格式**：内核镜像的加载和执行机制
4. **实践汇编与C混合编程**：引导阶段的协作方式
5. **熟悉xv6代码结构**：通过添加注释深入理解关键代码
